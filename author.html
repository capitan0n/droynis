Who am I?

I’m Alexandros.

@capitan0n · Greece

I build security and privacy tools for Android and Linux. Droynis is my Android project. It shows the evidence behind a finding so you can decide what to change on your phone.

I study Electrical and Computer Engineering at the University of Peloponnese, specializing in Computer Science. My interests include system hardening, digital forensics and self-hosting.

Other projects

dnser

A Python command-line tool for switching DNS on Linux. It can compare resolvers, enable DNS over TLS and roll back a change.

pipx install dnser

sshd-lint

A static analyzer for OpenSSH server configuration. It checks sshd_config for hardening issues before a configuration goes live.

pipx install sshd-lint

probolos Beta

A USB access tool that keeps new devices blocked until you approve them. It checks device identity, behavior and storage before you decide.

pipx install probolos==1.0.0b2

audiotap

Records system audio on Linux. When the player changes tracks, audiotap starts a new file and tags it with the artist, album and track title from the player.

Install from GitHub · PyPI release planned

Verify a GitHub APK

Replace <version> with the downloaded release version. The first command checks the APK against its published checksum; the second verifies GitHub’s build attestation with the GitHub CLI.

sha256sum -c droynis-<version>.apk.sha256
gh attestation verify droynis-<version>.apk --repo capitan0n/droynis

Each release also publishes the signing certificate’s SHA-256. Check it on first install, for example with AppVerifier; Android rejects later updates signed with a different key.

Does Droynis fix settings automatically?

No. It audits the phone it runs on, explains findings, shows evidence and opens the relevant Settings screen. You decide what to change.

Does anything leave my phone?

The app has no INTERNET permission, no Google Play Services dependency and no analytics. Data leaves only if you choose to share a report. Personal network and computer details are hidden in reports by default.

Is this an antivirus?

No. Droynis does not scan apps for malicious code or remove apps. It looks at configuration and suspicious app indicators. Version 1.1.0 removed the known-stalkerware detector and its list. SUSP-5007 now shows N/A and does not affect your score.

Do I need root?

No. The Base tier needs no setup and has 72 entries in the 1.1.0 catalog, including the inactive check. ADB, Shizuku and root offer optional visibility into more checks. Root stays off until enabled in the app.

What does Unknown mean?

Android did not provide a value Droynis could read reliably. Unknown and N/A results are excluded from the score. Droynis never reports Passed simply because it could not read a setting.

Can I save and compare reports?

Yes. Export Markdown for reading or JSON for tools. JSON uses stable ordering so you can compare scans with diff. Optional scheduled scans run about daily or weekly, subject to Android battery limits.

# Security policy

Droynis is read-only and has no network access, but a flaw can still matter: a check that passes
when it shouldn't, a privileged read (ADB, Shizuku or root) doing more than documented, or a report
that leaks personal details.

## Reporting a vulnerability

Report it privately, through [GitHub's private reporting](https://github.com/capitan0n/droynis/security/advisories/new)
or by email to capitan0n@protonmail.com. Include the Droynis version, the phone, the Android version
and the tier. You'll get an answer within a week, and credit in the release notes if you want it.

A wrong result that can't be abused is not a vulnerability: open a regular "Wrong result" issue.

## Supported versions

Only the latest release gets fixes.

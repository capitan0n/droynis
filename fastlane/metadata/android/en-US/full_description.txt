Droynis checks the security and privacy settings of the phone it runs on, explains every finding in plain words, shows the raw evidence and opens the Settings screen that fixes it. It never changes anything itself.

Droynis is not an antivirus or malware scanner: it audits how the phone is set up and looks for signs that adware leaves, not for malicious code.

<b>What it checks</b>
<ul>
<li>Device integrity: security patch age, vendor and kernel patches, encryption, bootloader lock, root, SELinux, WebView updates, time since restart, storage space</li>
<li>Access control: screen lock and its strength, biometric unlock strength, lock delay, remote lock and erase, USB and wireless debugging and their authorization timeout, Smart Lock, SIM PIN, device controls on the lock screen</li>
<li>Apps and permissions: accessibility services, device admins, notification access, SMS and call log access, location all the time, autofill and assistant apps, passkey and password providers, apps with Shizuku access, clipboard access alerts, sideloaded and debuggable apps, special app access, apps that skip battery optimization, Google Play services</li>
<li>Suspicious apps: apps that hide from the app drawer (turned-off icon, blank name, transparent icon), hidden apps set up to run in the background, running in the background or showing screens of their own, camera, microphone, location, SMS, call log and contacts use from the background, apps that record the screen without asking, apps installed by another app, banking-trojan permissions, and apps signed with a debug or test key</li>
<li>Network and radios: Private DNS, VPN, Wi-Fi security and MAC randomization, open Wi-Fi networks that join automatically, hidden Wi-Fi networks, hotspot security, HTTP proxies, user and added system certificates, 2G, mobile network encryption, Bluetooth, NFC and Secure NFC, location</li>
</ul>

<b>Four tiers</b>
Most checks need no setup. Two read-only adb grants, Shizuku or root unlock the rest; privileged tiers run only a fixed list of read-only commands.

<b>Honest results</b>
A check passes only on a value it actually read. When Android won't say, the result is Unknown, never Passed. A score from 0 to 100 sums it up; checks you can't fix can be muted.

<b>Scheduled scans</b>
Optional: Droynis scans about once a day or once a week in the background and compares with the last results. Notifications, off until you turn them on, say what got worse, got fixed or couldn't run.

<b>Private by design</b>
No internet permission, no Google Play Services, no analytics. Reports (Markdown or JSON) leave out IP addresses, DNS and proxy servers and trusted computers by default.
